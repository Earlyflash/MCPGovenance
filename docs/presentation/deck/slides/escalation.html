About 1 minute. Some guardrails apply only from a later stage, and some get stricter. The container running as root is a good example: a warning for a pilot, a block for production. Accessibility is advice-only, so even its blocking rules show as warnings. The developer is told early, so they fix it before the last minute. In the demo, the promotion pull request shows this live.
